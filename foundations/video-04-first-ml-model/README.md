# Video 4 - Train Your First Machine Learning Model

In this video we build our first complete machine learning workflow.

## What We Build

- Load dataset
- Train model
- Evaluate model
- Save model artifact
- Load model
- Run inference

## Files

### train.py

Trains a Random Forest model.

### predict.py

Loads saved model and performs inference.

## Install

```bash
python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt
```

## Run Training

```bash
python train.py
```

## Run Inference

```bash
python predict.py
```
